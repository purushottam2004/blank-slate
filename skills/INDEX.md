# Introduction

This is a collection of skills which agents can use to perform tasks.
These skills can be copied into respective agent's directory and used by the agent.

## Index

| Skill | Description | Is Ready |
|-------|-------------|----------|
| [grill-me](grill-me/SKILL.md) | Relentless interview to sharpen a plan or design. Invokes [grilling](grilling/SKILL.md). Writes no files. | Yes |
| [grill-with-docs](grill-with-docs/SKILL.md) | Same interview, and it records terms and decisions. Invokes [grilling](grilling/SKILL.md) and [domain-modeling](domain-modeling/SKILL.md). | Yes |
| [grilling](grilling/SKILL.md) | The interview itself: one round per frontier, recommended answer on each question. | Yes |
| [domain-modeling](domain-modeling/SKILL.md) | Writes `GLOSSARY.md` and ADRs as terms and decisions settle. | Yes |
| [Setting Up File Structure](setting-up-file-structure/README.md) | | No |
