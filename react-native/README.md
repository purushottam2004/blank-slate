# React Native

Expo app (SDK 58) that signs in with Supabase and calls the FastAPI `GET /api/v1/hello` route. One TypeScript codebase runs on iOS, Android, and the web. It sits next to `frontend/` and `android/` because Metro is its own bundler. Those directories are unchanged.

The folder is `react-native/`. The npm package name is `blankslate-react-native`, because the name `react-native` is the library this app depends on.

## Layout

Everything you edit is under `src/`. There is no second source tree.

| Path | What it is |
| --- | --- |
| `src/app/` | Screens. Expo Router turns each file into a URL. `login.tsx` is `/login`. `index.tsx` is `/`. `_layout.tsx` is the navigator, not its own page. |
| `src/auth/` | Session state. Screens call `useAuth()`. They do not construct the Supabase client. |
| `src/lib/` | Supabase client, FastAPI client, and the Android emulator host rewrite. |
| `src/components/` | Widgets that are not screens, such as the Hello button. |

A file inside `src/app/` becomes a route. That is why `supabase.ts` lives in `src/lib/` and not beside `login.tsx`.

`ios/` and `android/` inside this folder are generated by Expo when you compile. Do not create them by hand, and do not confuse a generated `react-native/android/` with the repo's Kotlin app at the repository root.

## Toolchain

| Piece | Version | Why |
| --- | --- | --- |
| Expo SDK | 58 | Current SDK. React Native 0.88, React 19.3 |
| Node.js | ≥ 22.13 | Same floor as the rest of the repo. SDK 58 requires it |
| pnpm | 11.17.0 | Same pin as `frontend/` |
| Expo Router | SDK 58 line | File routes in `src/app/` |
| Web | react-native-web, output `single` | One page app, same shape as the Vite apps. FastAPI stays the API |
| Auth storage | expo-sqlite `localStorage` | Expo's Supabase session store. The import is a no-op on web |
| Styling | React Native `StyleSheet` | Login and home are small screens. Add NativeWind later if you want Tailwind `className`s |
